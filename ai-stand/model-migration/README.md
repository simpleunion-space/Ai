# Миграция embedding-индексов

Миграция создаёт новое поколение индекса из сохранённых текстов и metadata, сверяет размерность с профилем модели и сохраняет прежнее поколение для восстановления. Исходные тексты, IDs и metadata не удаляются. Запуск требует явной установочной команды model-migrate-q4 и защищённых state/backup; не запускайте миграцию как часть обычного повторного deploy.

verify-candidate.py остаётся внутренним этапом миграции: он сверяет exact model/image bindings и подготовленные артефакты. Удаление тестовых файлов не меняет сохранность пользовательских LanceDB данных.
